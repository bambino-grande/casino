# Kazik

Казино на внутриигровой валюте **наеБАЛЛЫ**: за джекпот в слотах игрок получает картинку-приз.
Кошелёк пополняется картой через API Z-банка (`https://karim.top/zbank`), донаты автору идут рублями по СБП мимо кошелька.
Оба платежа работают через один интерфейс оплаты.

Лабораторная работа №1, серверная часть: модульный монолит на Kotlin + Spring Boot, проверяется через Swagger.

## Что умеет

| Возможность | Как работает |
|---|---|
| Регистрация и вход | `POST /auth/register` создаёт пользователя в Keycloak, вход — кнопкой **Authorize** в Swagger |
| Кошелёк | баланс и история; под капотом журнал двойной записи |
| Пополнение | оплата картой Z-банка прямо в запросе, наеБАЛЛЫ по курсу 1 к 1 |
| Слоты | «Капибара Классик»: 3 барабана, прогрессивный джекпот; три 🦫 — джекпот и анимация `CAPYBARA_RAIN` |
| Призы | за джекпот — случайная картинка из `server/prizes`, видна только владельцу |
| Донат автору | реквизиты СБП и код-комментарий; донат сразу попадает на стену донатеров |

## Запуск

```bash
cd server
cp .env.example .env
docker compose up --build
```

| Что | Адрес |
|---|---|
| Swagger | http://localhost:8081/swagger-ui.html |
| Keycloak (админка) | http://localhost:8080, логин и пароль — `KEYCLOAK_ADMIN*` из `.env` |
| PostgreSQL | `localhost:5544` |

Роли: `USER` играет, пополняет и донатит; `ADMIN` смотрит любые раунды, призы и платежи.
Демо-пользователи `player` (USER) и `admin` (ADMIN), пароль — `KAZIK_DEMO_PASSWORD` из `.env`.

### Сценарий в Swagger

1. `POST /api/v1/auth/register` или взять `player`.
2. **Authorize** → `client_id` = `kazik-swagger` → войти на странице Keycloak.
3. `POST /api/v1/payments/top-ups` с `Idempotency-Key`, суммой и картой Z-банка → `SUCCEEDED` или `422` с причиной.
4. `GET /api/v1/wallet` — через секунду там наеБАЛЛЫ.
5. `POST /api/v1/games/slots/capy-classic/spins` — крутить; повтор с тем же ключом второй раз не списывает.
6. За джекпот в ответе спина есть `prize`; коллекция — `GET /api/v1/rewards/prizes`.
7. `POST /api/v1/donations` — донат; стена — `GET /api/v1/donations`.

Картинки-призы — файлы в `server/prizes` (`png`, `jpg`, `webp`, `gif`, `svg`), git их не отслеживает, кроме образцов.

## Тесты

```bash
cd server
./gradlew integrationTest
```

Интеграционные тесты на PostgreSQL в Testcontainers: гонки ставок, идемпотентность, ответы Z-банка (WireMock),
двойная запись, джекпот и призы, права доступа, миграции и обработка всех исключений.

## Архитектура

```
server/kazik/src/main/kotlin/ru/pogosian/kazik/
├── config/      security, Swagger
├── common/      деньги, id, ошибки, traceId, шина событий
├── identity/    регистрация через Keycloak
├── wallet/      кошелёк, журнал двойной записи
├── payments/    оплата: Z-банк, СБП, outbox
├── games/       слоты, раунды, джекпот
└── rewards/     призы
```

В каждом модуле слои `business` (домен и сервисы), `infrastructure` (репозитории на `JdbcClient`, внешние API),
`presentation` (контроллеры, DTO) и `security`. Модули общаются в одном процессе: `games` вызывает кошелёк и призы,
`payments` сообщает кошельку об оплате событием через outbox. Миграции разбиты по модулям: `001-wallet` … `004-rewards`, `005-data`.

Спин — одна транзакция: любой сбой откатывает ставку, выигрыш и раунд целиком.
Платёж Z-банка идёт вне транзакции; если ответ потерялся, повтор с тем же ключом и картой завершает его без второго списания.

## Ошибки

Тело: `{code, message, status, timestamp, traceId}`.

| Статус | Когда |
|---|---|
| 400 | неверные данные |
| 401 / 403 | нет токена / нет прав |
| 404 | не найдено |
| 409 | ключ идемпотентности уже использован, параллельный повтор |
| 422 | не хватает наеБАЛЛОВ, банк отказал |
| 503 | Z-банк или Keycloak недоступны |
